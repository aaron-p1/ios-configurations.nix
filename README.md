iOS configuration (only profiles for now) generated by the Nix module system
and deployed via a single command (optionally even [wirelessly](#wireless-deployment)).

Available profile options are taken from an
[official source](https://github.com/apple/device-management/tree/release/mdm/profiles)
and are [documented](#documentation)
and validated (See [validation](#validation) section).

iOS configuration profiles can be loaded onto iOS devices to configure various settings
even some that are not visible in the Settings app. The problem is that manually writing
a `.mobileconfig` file and loading it onto the device wirelessly is not trivial.
(finding the documentation,
writing the mobileconfig in the hardly readable plist format by hand,
manually checking every profile property if it is valid and supported,
may be hard to find a way to enable wireless loading of profiles)

This project aims to make it way easier:

1. Edit the configuration options
2. Plug in the iOS device via USB (or enable [wireless deployment](#wireless-deployment) to skip this step)
3. `nix run .#deploy-<device_name>` to deploy the configuration to your device.
4. On unsupervised devices the iOS device needs to be unlocked when loading the profile
   and the installation has to be confirmed on the device.

Supervised device deployment is not supported yet.
It will probably be implemented when I get a new phone this year.
(Still possible to use this project to generate the mobileconfig file
and load it manually via program that supports supervised connections)

Specifying multiple profiles of the same type is not implemented yet.

This project was tested on Linux and iOS 16 but should work on MacOS and other iOS versions as well.
Most profiles were not tested.

## Usage

Init with:

```bash
nix flake init -t github:aaron-p1/ios-configurations.nix
```

If you don't want to `nix flake init`, look at the [template file](/templates/usage/flake.nix)
in this project for reference.

In the `flake.nix` the `iosConfigurations` key should be edited:

```nix
{
  iosConfigurations = {
    iphone = iosConfig {
      modules = [
        {
          target = {
            version = "16.7";
            isSupervised = false;
            udid = null;
          };
          profiles = {
            enable = true;
            # Example: recommended quad9 config
            # (same as https://docs.quad9.net/Setup_Guides/iOS/iOS_14_and_later_%28Encrypted%29/)
            dnsSettings-managed = {
              enable = true;
              PayloadDisplayName = "Quad9 DoH";
              DNSSettings = {
                DNSProtocol = "HTTPS";
                ServerAddresses = [
                  "9.9.9.9"
                  "149.112.112.112"
                  "2620:fe::fe"
                  "2620:fe::9"
                ];
                ServerURL = "https://dns.quad9.net/dns-query";
              };
              OnDemandRules = [
                {
                  Action = "EvaluateConnection";
                  ActionParameters = [
                    {
                      DomainAction = "NeverConnect";
                      Domains = [
                        "dav.orange.fr"
                        "msg.t-mobile.com"
                        "ip.videotron.ca"
                        "vvm.ee.co.uk"
                      ];
                    }
                  ];
                }
                {
                  Action = "Connect";
                }
              ];
            };
          };
        }
      ];
    };
  };
}
```

Deploy with:

```bash
nix run .#deploy-iphone
```

## Validation

Profile property types (and sometimes ranges and formats) are validated (of course).
Most of these validations are taken from the
[official source](https://github.com/apple/device-management/tree/release/mdm/profiles).

Some missing assertions were added.
For example, the profile `webcontent-filter` requires `ContentFilterUUID` to be set
on unsupervised devices.
If you find any other missing assertions (installing the profile on the device
gives an error message saying the profile is somehow invalid), feel free to open an issue or PR.
(Assertions are defined [here](/modules/profiles/overrides.nix))

Options that need certain iOS versions or a supervised device can
be validated by setting the `target.version` and `target.supervised` keys in the configuration.
If these keys are `null` (default), options are not validate against them.

(`nix flake check` can check the configuration.)

## Documentation

A man page of all options is available and in the [flake template](/templates/usage/flake.nix)
it is added to the devShell environment.

```bash
nix develop # or use direnv
man ios-configurations
```

The man page is also converted to markdown and can be viewed [here](/docs/options.md).

## Wireless deployment

Linux requirements:

- usbmuxd server that supports wireless connections
  - [usbmuxd2](https://github.com/tihmstar/usbmuxd2) (not tested on, but should work)
  - [netmuxd](https://github.com/jkcoxson/netmuxd) (not in nixpkgs as of 2026-09-06)
- mDNS service (e.g. `avahi-daemon` on Linux, `services.avahi` option on NixOS)
- the iOS device and config host need to be in the same local network

I don't know what is required on MacOS. I think everything is already built in.

### Enable wireless deployment

The project [pymobiledevice3](https://github.com/doronz88/pymobiledevice3) has this feature implemented:

```bash
pymobiledevice3 lockdown wifi-connections [on,off]
```

But in nixpkgs a dependency of this package has been broken for months,
so an alternative way is described below.

### Alternative way to enable wireless deployment

1. Connect iOS device via USB and check for current wireless status:

```bash
# from package `libimobiledevice` (in nixpkgs)
ideviceinfo -q com.apple.mobile.wireless_lockdown
# or
nix run github:aaron-p1/ios-configurations.nix#wireless-config
# or
nix run github:aaron-p1/ios-configurations.nix#wireless-config -- --udid <device_udid>
```

It should show `EnableWifiConnections = false` if not already enabled.

2. Enable wireless connection:

```bash
nix run github:aaron-p1/ios-configurations.nix#wireless-config true
```

3. Disconnect the device from USB and check if still reachable:

```bash
# from package `libimobiledevice` (in nixpkgs)
idevice_id -nl
```

It should show a line with `"<udid> (Network)"`.

If it is not shown, try disabling and re-enabling wifi on the device and check again.
The connection can sometimes feel unstable.

## Missing Features

- Supervised device deployment
- Specifying multiple profiles of the same type
- More options than just profiles (e.g. installed apps)
- Higher level options for easier configuration
  (like how NixOS as `services.*` and `systemd.services.*` options)
- A lot more assertions to prevent deploying invalid configurations
- Maybe overriding some config descriptions
- Maybe better output when deploying profiles
  (currently [go-ios](https://github.com/danielpaulus/go-ios) outputs json
  which is then pretty printed)
